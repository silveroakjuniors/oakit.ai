Admin User Guide

Silver Oak Juniors  ·  oakit.silveroakjuniors.in

Role: Admin  —  Full access to all school data and settings

1. What is Oakit.ai and What Can an Admin Do?

Oakit.ai is an AI-powered school management platform connecting teachers, parents, and leadership in one place. The AI assistant Oakie helps teachers plan lessons, generate content, and communicate with parents.

As Admin, you have full control over everything within your school — the only role with access to fees, HR salary, school settings, and system configuration.

2. Logging In

1
Open https://oakit.silveroakjuniors.in in any browser (Chrome, Safari, Firefox).
2
Enter your mobile number and password. Tap Sign In.
3
The system redirects you automatically to the Admin portal.
If you are locked out

Contact your Franchise Admin or Super Admin to reset your password. Only a Super Admin can reset an admin account directly from the platform.

Session Security

Sessions expire after 8 hours of inactivity. If another device logs into your account, your current session ends automatically. Never share your login credentials. The admin account has access to fee records, salary data, and student PII.

4. Student Management

4.1 Adding a New Student

1
Go to Admin → Students → Add Student.
2
Fill in: name, date of birth, section, parent names, parent mobile numbers, and emergency contact.
3
Click Save. The student is now enrolled and visible to their section teacher.
Bulk import via Excel

To add many students at once: download the Excel template from the Students page, fill in all rows (one student per row), and upload it back. The system validates each row and shows errors before importing anything.

4.2 Editing a Student

Click the student name → Edit. You can change section, parent details, date of birth, photo, and emergency contacts. Changes take effect immediately.

4.3 Uploading a Student Photo

Open the student profile and tap the photo area. Upload a JPG or PNG (max 5 MB, face clearly visible). Photos appear in the parent app, teacher attendance view, and ID cards.

4.4 Deactivating a Student

When a child leaves the school: open the student profile → Deactivate. Historical data (attendance, fees, progress) is retained for records. The student is removed from active lists, attendance, and fee calculations.

Do not delete — always deactivate

Deleting a student permanently removes all their historical data: attendance records, fee history, curriculum progress, and observations. This cannot be undone. Always use Deactivate.

4.5 Promoting Students

At year end, go to Admin → Students → Promote. Select a class and move all students up to the next class. Students without a destination class are marked as graduated/left.

5. Teacher Management

5.1 Adding a Teacher

1
Go to Admin → Teachers → Add Teacher.
2
Enter name, mobile number, email. Set a temporary password.

Assign one or more sections. The teacher will only see students and plans from their assigned sections.
4

5.2 Resetting a Teacher Password

Go to Admin → Teachers → click the teacher name → Reset Password. Enter a new temporary password, share it securely with the teacher.

5.3 Reassigning Sections

Open the teacher profile → Edit → modify the sections list. The teacher immediately loses access to removed sections and gains access to added ones.

5.4 Deactivating a Teacher

Use Deactivate (not delete) to preserve attendance, coverage, and feed history linked to that teacher. A deactivated teacher cannot log in.

6. Parent Management

6.1 Adding a Parent and Linking Children

1
Go to Admin → Parents → Add Parent.
2
Enter name and mobile number. The mobile number is their login ID.
3
Link one or more children using the student search field.
4
Share the app URL and their mobile number as the login. Default password is their mobile number — they can change it in Settings.

6.2 The Instagram Follow Prompt

When a parent logs in for the first time (or until they click "I've followed"), they see a popup asking them to follow the school's Instagram page. This is automatic — no admin action needed once the Instagram handle is configured in Settings. You can track which parents have acknowledged this in the database.

Why parents matter in Oakit

Active parents reduce the number of phone calls the school receives. When parents can see attendance, homework, and daily photos in the app, they stop WhatsApp-messaging teachers for updates. This saves teacher time significantly.

7. Curriculum Management

7.1 Uploading a Textbook PDF

1
Go to Admin → Curriculum → Upload PDF.
2
Select the class and subject. Upload the PDF (max 50 MB per file).
3
Oakit's AI automatically extracts topics, chunks them into daily-sized units, and indexes them for Oakie's lesson planning.
4
Status shows "Processing" (2–5 minutes) then "Ready". Teachers can use it once it shows "Ready".
Upload curriculum before generating plans

If you upload new curriculum after plans are already generated, the new topics will not appear in existing plans. You must delete and regenerate the plans for the affected months. See Section 11 for how to regenerate.

7.2 Multiple PDFs Per Class

You can upload multiple PDFs for one class (e.g. English + Maths + EVS). Oakie knows each subject's topics separately and can answer subject-specific questions.

8. Academic Calendar Setup

The academic calendar defines when school starts and ends, which days of the week are working days, and what the academic year code is (e.g. 2025-2026). This must be set up before you can generate plans.

1
Go to Admin → Calendar.
2
Click New Calendar. Enter the academic year, start date, and end date.
3
Select working days (tick Monday through Friday, or your school's working days).
4
Click Save Calendar. The calendar is now the foundation for all plans, attendance, and coverage calculations.
Set the calendar before the academic year begins

Changing the calendar after plans have been generated can invalidate existing plans. Set it up once, correctly, at the start of the year.

9. Holidays

What is a Holiday?

A holiday is a day when school is completely closed — no teachers, no students. Examples: Diwali, Independence Day, a sudden government-declared holiday.

Effect on plans: The topic assigned to that day carries forward to the next working day. All subsequent topics shift by one day.

9.1 Adding a Holiday

1
Go to Admin → Calendar → Holidays tab.
2
Click Add Holiday. Enter the date and event name (e.g. "Republic Day" or "School Closed — Water Supply Repair").
3
Click Save.
4
If plans exist for that date, a yellow warning appears: "X section plans were cleared. Refresh the planner to shift topics forward."
5
Select the affected class below and click Refresh Planner. This shifts all topics forward automatically. Done.
Always click Refresh Planner after adding a holiday

Adding a holiday clears that day's plan but does NOT automatically shift subsequent days. The Refresh Planner step is mandatory. If you skip it, teachers will see a blank day followed by a gap in the topic sequence.

9.2 Editing or Deleting a Holiday

Go to Admin → Calendar → Holidays. Click the holiday → Edit or Delete. After deleting a holiday, the day becomes a working day again — plans need to be refreshed or the month regenerated to fill the freed slot.

9.3 Exporting the Holiday Calendar

Use the Export button to download all holidays as a CSV file. Use this to share the academic calendar with parents or staff.

10. Special Days

What is a Special Day?

A special day is a school-open day where either no curriculum happens (full day event) or less curriculum happens (half day event). Unlike holidays, the school is open — but teachers and students are doing something other than the regular timetable.

TypeSchool open?Curriculum taught?Topic carry-forward?Example
HolidayNoNoYes — full carry-forwardDiwali, sudden closure
Special Day — Full DayYesNoYes — full carry-forwardAnnual Day, Sports Day
Special Day — Half DayYesHalf (0.5 days)No — topic stays, reduced timeMorning assembly programme, Fancy Dress
Why half-day events exist

A half-day special day tells the teacher: "You have less teaching time today." The topic is still assigned, but the teacher knows to adjust the depth. For example: "Fancy Dress competition 9–11 AM. Regular class after 11 AM." The net curriculum days count is reduced by 0.5 for coverage calculations.

1
Go to Admin → Calendar → Special Days tab.

Click Add Special Day.
3

11. Lesson Planner — Complete Guide

11.1 How the Planner Works

When you generate plans for a class, Oakit does exactly this:

  1. Looks at the academic calendar (start date, end date, working days)
  2. Removes all holidays and full-day special events from the working day count
  3. Takes the curriculum chunks (topics extracted from the uploaded PDF)
  4. Distributes one topic per working day, in order
  5. If a day gets cleared later (holiday added), that day's topic carries forward to the next available working day — no topic is ever lost
The key principle: carry-forward

Oakit never discards a topic. If Day 15 becomes a holiday, Day 15's topic shifts to Day 16, Day 16's to Day 17, and so on. The plan compresses intelligently — the academic year just ends slightly later than originally planned.

11.2 Carry-Forward Scenario — Exactly What Happens

Concrete example: sudden holiday on Wednesday 15 January

Plan before the holiday:

  • Mon 13 Jan — Numbers 1–10
  • Tue 14 Jan — Addition basics
  • Wed 15 Jan — Subtraction intro ← you add a holiday here
  • Thu 16 Jan — Shapes
  • Fri 17 Jan — Colours

After adding the holiday and clicking Refresh Planner:

  • Mon 13 Jan — Numbers 1–10 (unchanged)
  • Tue 14 Jan — Addition basics (unchanged)
  • Wed 15 Jan — HOLIDAY (no topic)
  • Thu 16 Jan — Subtraction intro (shifted from Wed)
  • Fri 17 Jan — Shapes (shifted from Thu)
  • Mon 20 Jan — Colours (shifted from Fri)

Every topic is preserved. The plan extends by one day at the end of the sequence.

11.3 Generating Plans

1
Go to Admin → Plans.
2
Select the Class and Section.
3
Choose the month (or select Full Year).
4
Click Generate Month Plans or Generate Full Year Plans.
5
The system distributes topics. Teachers immediately see their daily plans.
Generate month-by-month vs full year

Full year generation is faster but locks everything in. Month-by-month gives flexibility — if something unexpected happens in December, you only regenerate December. Recommended approach: generate month-by-month at the start of each month, after adding any special days or holidays for that month.

11.4 Regenerating Plans (Delete + Regenerate)

Use Refresh Planner for carry-forward adjustments after adding holidays/special days.

Use Delete All Plans + Generate only when you need to completely redo a month — for example if you uploaded new curriculum, or the month's sequence is severely out of order.

You cannot regenerate a month that already has plans

The system prevents overwriting existing plans to protect teacher work. To regenerate:

  1. Go to Admin → Plans → select the class and month
  2. Click Delete All Plans for that month
  3. Then click Generate Month Plans
Teacher completion records are NOT deleted — only the daily topic assignments reset.

12. Editing Day Plans

12.1 Adding an Admin Note to a Day

Go to Admin → Plans. Click on any day card. Use the Admin Note field to add instructions visible only to the teacher for that specific day. This appears as a blue highlighted box in the teacher's daily view.

Examples of admin notes:

  • "Use the new chart from the storeroom today."
  • "PTM preparation — brief parents on today's topic during pick-up."
  • "Nursery annual day rehearsal from 11 AM — shorten today's lesson."

12.2 Changing a Topic Label

Click the day → Edit → modify the topic display name. The underlying AI still uses the original topic internally for Oakie queries. Use this to simplify topic names for teacher display.

12.3 Adding a Topic Not in the Curriculum

How to add an out-of-curriculum topic

If the school wants to add a topic not in the uploaded textbook (e.g. a special environmental awareness lesson):

  1. Go to Admin → Plans → find the target day
  2. Click the day → Add Admin Note
  3. Write the full topic and instructions: "Today's additional topic: Environmental Awareness — discuss waste sorting, recycling, and conservation with the class. Use the display board in the corridor."
  4. Save. The teacher sees this highlighted in blue on their daily plan.
For a permanent addition to the curriculum, upload a new PDF section and re-ingest it.

13. Coverage Report

Go to Admin → Coverage. This shows how much of the curriculum each section has actually completed (not just planned).

ColumnMeaning
SectionClass name and section label
Total chunksTotal curriculum topics for that class
CoveredTopics ticked as done by the teacher
Coverage %Covered ÷ Total × 100
FlaggedAdmin or principal has flagged this section for attention
Coverage vs Plans — the key difference

Plans tell you what was scheduled. Coverage tells you what was actually taught. A section can have 100% plans generated but only 40% coverage if teachers are not ticking topics. Coverage is the real metric of learning progress.

Sections below 60% warrant a conversation with the teacher. Sections below 40% need urgent action — check if plans were generated, if the teacher is using the app, and if there are unresolved carry-forward issues.

14. Class Feed

The Class Feed is where teachers post daily photos and videos of classroom activities. Parents see these in real time in the Oakit parent app. All media is stored in Google Drive.

14.1 Feed Settings

Go to Admin → Settings → Feed Settings:

  • Daily post limit per section — prevents flooding (recommended: 5 posts/section/day)
  • School-wide daily limit — total across all sections
  • Retention days — how long posts remain visible (recommended: 20–30 days)
Why set retention days

Feed posts are not meant to be permanent galleries. 20–30 days is enough for parents to see recent activity. Shorter retention keeps the feed fresh. For long-term memories, use Student Notes and Observations — not the feed.

14.2 Deleting a Feed Post

Admins can delete any post. Go to Admin → Feed → find the post → click the delete icon. Use this if inappropriate content is posted or if a parent requests removal.

15. Social Media Publisher

Module activation required

This module must be enabled by your Franchise Admin or Super Admin before it appears. Once enabled, go to Admin → Social Media.

15.1 Platform Setup (one time)

1
Go to Admin → Social Media → Platform Setup. The page opens here by default.
2
For Instagram: enter your Page Access Token, Instagram Business Account ID, Facebook Page ID, handle, Meta App ID, and App Secret. Follow the step-by-step guide shown on the page.
3
For Facebook: enter Page Access Token, Page ID, handle, Meta App ID, and App Secret.
4
Click Test Connection for each platform to verify credentials are working. A green tick confirms success.
Token expiry — act before it expires

Meta tokens expire every 60 days. The platform warns you 7 days before expiry. Click Refresh Token immediately when you see this warning. If the token expires, all teacher posts will fail to publish and you will need to generate a new token from the Meta Developer Console.

15.2 Meta App Review — Required for Public Publishing

If posts fail with the error "pages_manage_posts not approved", your Meta Developer App needs to pass App Review. Go to developers.facebook.com → your app → App Review → request the pages_manage_posts permission. Until approved, publishing only works for accounts added as test users.

15.3 Approval Queue — Your Most Time-Sensitive Task

When teachers submit posts, a red badge appears on the Social Media tab. Check this daily.

1
Go to Admin → Social Media. The Approval Queue tab opens by default.
2
Review the photo/video, caption, and selected platforms for each post.
3
Click Approve & Publish to send live, or Reject with a written reason.
4
Approved posts publish within 30–60 seconds. The teacher receives an in-app notification with a link to the live post.
Bulk approve

Select multiple posts using the checkboxes and click Approve all to publish them simultaneously. Use this at the end of the day when multiple posts are queued.

15.5 Deleting a Published Post from Instagram/Facebook

Go to Post History, find the post, and click the red Delete post button next to the platform badge. This calls the Graph API and removes the post from Instagram or Facebook directly. The post record remains in Oakit history.

15.6 Retrying Failed Posts

If a post failed (expired token, temporary API error), read the error message shown below the platform badge. After fixing the issue (e.g. refresh the token), click Retry Failed Platforms. The system only retries the platforms that failed — successful platforms are not affected.

Media deleted warning

If the post card shows "Media files were deleted — ask teacher to resubmit", the Drive file was deleted before retry was possible. The teacher must upload the photos/video again and submit a new post.

16. Google Drive Bulk Cleanup

Every photo, video, and file uploaded by teachers lands in your school's Google Drive. Over time this fills up. The Drive Cleanup tool deletes all old files in bulk after notifying parents first.

What gets deleted: All teacher-uploaded files older than your chosen cutoff — class feed photos/videos, teacher media, social media post files, student notes, homework files.

16.1 When to Run a Cleanup

  • At the end of each term (every 3–4 months)
  • When Google Drive shows less than 20% free storage
  • Before the start of a new academic year

16.2 Step-by-Step Cleanup Process

Notify parents first — mandatory

Parents cannot recover files after deletion. Always run Step 2 (Notify) and give parents at least 7 days to download photos/videos before running Step 3 (Delete).

1
Go to Admin → Settings → Google Drive Cleanup (or directly to /admin/drive-cleanup).
2
Set "Delete files older than" to 30 days (minimum 7).
3
Set "Notify parents (days before delete)" to at least 7.
4
Click Preview files to delete. The system shows file count, size, and which classes are affected — before deleting anything.
5
Click Notify parents. This sends a popup to all affected parents with a warning, the deadline, and a link to their class Drive folder.
6
Wait the notification period (7+ days).
7
Return to the cleanup page, type DELETE in the confirmation box, click Delete files permanently.

17. Fee Management

Financial module must be enabled

The fee module requires the Financial module to be enabled for your school. Contact your Franchise Admin if fee options are not visible.

17.1 Setting Up a Fee Structure

Go to Admin → Fees → Fee Structures → New Structure. Add line items (tuition, activity fee, transport, etc.) with amounts. Assign the structure to a class or section.

17.2 Recording a Payment

1
Go to Admin → Fees → Students. Find the student by name or ID.
2
Click Record Payment. Enter amount, payment mode (cash/online/cheque), and date.
3
The system generates a receipt automatically. Download and share with the parent.

17.3 Concessions

Go to Admin → Fees → Concessions. Create a concession (e.g. "Sibling discount — 10%") and apply it to a student's record. Concessions appear on the invoice.

17.4 Defaulter Report

Go to Admin → Fees → Reports → Defaulters. This lists all students with outstanding dues sorted by amount owed. Use this for follow-up calls.

18. HR & Staff

18.1 Staff Records

Go to Admin → HR → Staff. Maintain: designation, joining date, salary grade, emergency contact, and document uploads.

18.2 Leave Management

Staff apply for leave through the app. Pending requests appear on your dashboard. Go to Admin → HR → Leave to approve or reject with a reason.

18.3 Offer Letters

Go to Admin → HR → Offer Letters. Select a template, fill in staff details, generate a PDF. Download or email directly.

18.4 Salary

Go to Admin → HR → Salary. Protected by a separate PIN (not your login password). Set up the PIN on first use. Enter monthly salary, deductions, and generate pay slips.

Salary PIN security

The salary PIN is separate from your login password. Keep it confidential. Only admin and principal can access salary data. Never write the PIN where others can find it.

19. Announcements & Flash Messages

19.1 Announcements

Go to Admin → Announcements → New. Write a title and body. Choose target: all parents, all teachers, or a specific class. Set an expiry date. Appears in the notifications tab of the parent and teacher apps.

19.2 Flash Messages (Full-Screen Popups)

Flash messages appear as full-screen popups the next time the user opens the app. Use for urgent communication.

1
Go to Admin → Announcements → Flash Messages → New Flash Message.
2
Enter title, body, target role (parent / teacher / all), start date, and end date.
3
The message shows to every matching user once per session, until the end date.
Best uses for Flash Messages
  • Sudden school closure or holiday notice
  • Fee payment deadline reminder
  • Parent-teacher meeting schedule
  • Google Drive cleanup warning (auto-generated)
  • Important notices that cannot wait for the next regular communication
