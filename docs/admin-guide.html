1. What is Oakit.ai and What Can an Admin Do?

Oakit.ai is an AI-powered school management platform. It connects teachers, parents, and school leadership in one place, with Oakie (the AI assistant) helping teachers plan lessons and communicate with parents.

As an Admin, you have full control over everything within your school. You are the only person who can configure the platform, approve teacher content, manage fees, and maintain the system.

ModuleWhat you manage
StudentsEnrol, edit, photos, promotions, deactivations
TeachersAccounts, section assignments, password resets
ParentsAccounts, child links, communication
CurriculumUpload textbooks, monitor class coverage
FeedApprove / delete posts, storage management
Social MediaPlatform credentials, approve posts, delete from Instagram/Facebook
FeesFee structures, collections, concessions, invoices

AnnouncementsSchool-wide and class-specific announcements

2. Logging In

1
Open https://oakit.silveroakjuniors.in in any browser.
2
Enter your mobile number and password, then tap Sign In.
3
The system automatically redirects you to the Admin portal.
If you are locked out

Contact your Oakit system administrator or Franchise Admin to reset your password. Only a Super Admin can reset an admin account password directly.

Session & Security

Sessions expire after 8 hours of inactivity. If another device logs into your account, you will be signed out automatically (cross-tab session replacement). Never share your login credentials.

4. Student Management

4.1 Adding a New Student

1
Go to Admin → Students.
2
Click Add Student. Fill in name, date of birth, section, and parent contact numbers.
3
Click Save. The student is now enrolled.
Bulk import

To add many students at once, download the Excel template from the Students page, fill it in, and upload it. The system validates each row and shows errors before importing.

4.2 Editing a Student

Click the student's name → Edit. You can change section, parent details, date of birth, and photo.

4.3 Uploading a Student Photo

Open the student profile and tap the photo area. Upload a JPG or PNG (max 5 MB). Photos appear in the parent app and teacher attendance view.

4.4 Deactivating a Student (when a child leaves)

Open the student profile → Deactivate. The student's data is retained for records but they are removed from active lists, attendance, and fee calculations.

Do not delete — deactivate

Deleting a student removes all their historical data including attendance, fee records, and progress. Always deactivate instead.

5. Teacher Management

5.1 Adding a Teacher

1
Go to Admin → Teachers → Add Teacher.
2
Enter name, mobile number, and email. Set a temporary password.
3
Assign one or more sections. The teacher will only see their assigned sections.
4
Share the login URL and credentials with the teacher. Ask them to change their password on first login.

5.2 Resetting a Teacher's Password

Go to Admin → Teachers → click the teacher's name → Reset Password. Enter a new temporary password and share it with them.

5.3 Removing a Teacher

Deactivate the teacher account rather than deleting — this preserves attendance, coverage, and feed history linked to that teacher.

6. Parent Management

6.1 Adding a Parent and Linking Their Child

1
Go to Admin → Parents → Add Parent.
2
Enter the parent's name and mobile number. This mobile number is their login ID.
3
Link one or more children using the student search field.
4
Share the app URL and credentials. The parent logs in with their mobile number.

6.2 Why Parents Matter in Oakit

Parents see their child's daily feed, attendance, homework, and progress through the parent portal. Active parents reduce the volume of phone calls and WhatsApp messages the school receives because they already have the information they need.

Instagram follow prompt

When a parent logs in for the first time, they see a popup asking them to follow the school's Instagram page. This automatically stops showing once they click "I've followed". You can track who has acknowledged this in the database.

7. Curriculum Management

7.1 Uploading a Textbook / Curriculum PDF

1
Go to Admin → Curriculum → Upload PDF.
2
Select the class / subject and upload the PDF. The file size limit is 50 MB.
3
Oakit's AI automatically extracts topics, chunks them, and indexes them for Oakie's lesson planning.
4
Indexing takes 2–5 minutes. You will see a "Processing" status until it's ready.

7.2 Monitoring Coverage

Go to Admin → Coverage. You can see per-section coverage percentages updated in real time as teachers mark topics as covered. Sections below 50% are highlighted on the dashboard.

When to upload curriculum

Upload all textbooks at the start of each academic year before teachers begin planning. Mid-year uploads work but teachers may need to re-plan sections that were already in progress.

8. Class Feed & Media

The Class Feed is where teachers post daily photos and videos of classroom activities. Parents see these in the Oakit parent app. All media is stored in Google Drive.

8.1 Feed Settings

Go to Admin → Settings → Feed Settings. You can configure:

  • Daily post limit per section — prevents teachers from flooding the feed (recommended: 5)
  • School-wide daily limit — total posts per day across all sections
  • Retention days — how long posts remain visible in the feed before auto-expiring (recommended: 20–30 days)
Why set retention days

Feed posts are not meant to be permanent galleries. 20–30 days is enough for parents to see recent activity. Shorter retention keeps the feed fresh and reduces storage. For long-term memories, teachers should use the student portfolio (notes and observations), not the feed.

8.2 Managing Feed Posts

Admins can delete any feed post. Go to Admin → Feed and click the delete icon on any post. Use this if inappropriate content is posted or if a parent requests removal.

9. Social Media Publisher

The Social Media Publisher lets teachers submit Instagram and Facebook posts for your approval. Nothing goes live without your sign-off.

Module activation

This module must be enabled by your Franchise Admin or Super Admin. Once enabled, go to Admin → Social Media to set up platform credentials.

9.1 Platform Setup (do this once)

1
Go to Admin → Social Media → Platform Setup.
2
For Instagram: enter your Page Access Token, Instagram Business Account ID, Facebook Page ID, and handle. You can get these from the Meta Developer Console. Follow the step-by-step guide shown on the page.
3
For Facebook: enter your Page Access Token and Page ID.
4
Click Test Connection to verify credentials are working.
5
Also enter your Meta App ID and App Secret so tokens can auto-refresh every 60 days.
Token expiry warning

Meta (Instagram/Facebook) access tokens expire every 60 days. The platform will warn you 7 days before expiry. Click Refresh Token to extend it immediately. If the token expires, all teacher posts will fail to publish.

9.2 Approval Queue — Your Daily Task

When teachers submit posts, you see a red badge on the Social Media tab. This is your most time-sensitive task.

1
Go to Admin → Social Media. The page opens on Approval Queue by default.
2
Review the photo/video, caption, and selected platforms for each post.
3
Click Approve & Publish to send it live immediately, or Reject with a reason if changes are needed.
4
Approved posts publish within 30–60 seconds. The teacher receives an in-app notification.
Bulk approve

Select multiple posts using the checkboxes and click Approve all to publish them all at once. Use this when you have many posts queued at the end of the day.

9.3 Post History — What to Check and When

Go to Admin → Social Media → Post History.

StatusMeaningAction
publishedLive on the platformUse "Delete post" button if removal is needed
partially publishedPosted to some platforms, failed on othersClick Retry Failed Platforms
failedAll platforms failedCheck the error message and retry, or fix credentials
pending approvalAwaiting your reviewGo to Approval Queue

Retrying Failed Posts

If a post failed because of an expired token or a temporary API error, the error message tells you what went wrong. After fixing the credential (e.g. refreshing the token), click Retry Failed Platforms on the post card. The system retries only the platforms that failed.

Media deleted warning

If the post shows "Media files were deleted — ask teacher to resubmit", the Drive file was deleted before retry was possible. The teacher must upload and submit the post again.

9.4 Deleting a Published Post from Instagram/Facebook

If a post needs to be removed from social media after publishing, go to Post History, find the post, and click the red Delete post button next to the platform badge. This calls the Graph API and removes it from Instagram or Facebook directly.

9.5 Caption Best Practices

  • Oakie generates captions automatically — always include the teacher's notes so the AI has context
  • Every caption includes #yippppppp and 20 reach-boosting hashtags automatically appended at publish time
  • Total hashtags are capped at 28 to stay within Instagram's 30-hashtag limit
  • Captions are capped at 2,200 characters (Instagram's limit)

10. Google Drive Bulk Cleanup

Every photo, video, and file uploaded by teachers is stored in your school's Google Drive. Over time this fills up Drive storage. The Drive Cleanup tool lets you delete all old files in bulk after notifying parents first.

What gets deleted: All teacher-uploaded files older than your chosen cutoff — class feed photos/videos, teacher media, social media post files, student notes, and homework files.

10.1 When to run a cleanup

  • At the end of each term (every 3–4 months)
  • When Google Drive shows less than 20% free space
  • Before the start of a new academic year

10.2 Step-by-step cleanup process

Important — notify parents first

Parents cannot recover files after deletion. Always run Step 2 (Notify) and give parents at least 7 days to download before running Step 3 (Delete).

1
Go to Admin → Settings → Google Drive Cleanup (or Admin → Drive Cleanup directly).
2
Set "Delete files older than" to 30 days (or your preferred number, minimum 7).
3
Set "Notify parents (days before delete)" to at least 7.
4
Click Preview files to delete. The system shows you exactly how many files, their size, and which classes are affected.
5
Click Notify parents. This immediately sends a popup to all affected parents with:
  • A warning that files will be deleted on a specific date
  • A link directly to the class Google Drive folder
  • Instructions to download before the deadline
6
Wait the notification period (7+ days).
7
Return to the cleanup page, type DELETE in the confirmation box, and click Delete files permanently.
What happens to the Oakit feed after cleanup

Feed posts remain visible in the parent app (text, comments, likes) but their photos/videos will no longer load. The posts expire naturally based on the retention period you set. This is expected behaviour.

11. Fee Management

11.1 Setting Up a Fee Structure

Go to Admin → Fees → Fee Structures. Create a structure with line items (tuition, activity fee, transport, etc.) and assign it to a class or section.

11.2 Recording a Payment

1
Go to Admin → Fees → Students, find the student.
2
Click Record Payment, enter the amount, payment mode (cash/online/cheque), and date.
3
The system generates a receipt automatically. Download and share with the parent.

11.3 Concessions and Discounts

Go to Admin → Fees → Concessions. Create a concession (e.g. "Sibling discount — 10%") and apply it to a student's fee record. Concessions show up on the invoice.

11.4 Defaulter Report

Go to Admin → Fees → Reports → Defaulters. This lists all students with outstanding dues sorted by amount. Use this for follow-up calls.

Financial module activation

The fee module requires the Financial module to be enabled for your school. Contact your Franchise Admin if you cannot see fee options.

12. HR & Staff

12.1 Staff Records

Go to Admin → HR → Staff. Maintain basic HR data: designation, joining date, salary grade, emergency contact, and documents.

12.2 Leave Management

Staff apply for leave through the app. You will see pending leave requests on the dashboard. Go to Admin → HR → Leave to approve or reject with a reason.

12.3 Offer Letters

Go to Admin → HR → Offer Letters. Select a template, fill in the staff member's details, and generate a PDF offer letter. The letter can be downloaded or emailed.

12.4 Salary

Go to Admin → HR → Salary. Salary records are protected by a PIN. Set up the PIN on first use. Enter monthly salary details, deductions, and generate pay slips.

Salary PIN security

The salary module uses a separate PIN that is not your login password. Keep this PIN secret. Only the admin and principal can access salary data.

13. Announcements & Flash Messages

13.1 School Announcements

Go to Admin → Announcements → New. Write a title and body. Choose target audience: all parents, all teachers, or a specific class. Set an expiry date. The announcement appears in the notifications tab of the parent and teacher apps.

13.2 Flash Message Popups

Flash messages show as full-screen popups the next time a parent or teacher opens the app. Use them for urgent communication.

1
Go to Admin → Announcements → Flash Messages → New Flash Message.
2
Enter title, body, target role (parent / teacher / all), start date, and end date.
3
The message shows as a popup to every matching user once per session, until the end date.
Use cases for Flash Messages
  • School closure or holiday notice
  • Fee payment deadline reminder
  • Parent-teacher meeting schedule
  • Drive cleanup notification (auto-generated by the cleanup tool)
  • Instagram follow prompt (auto-generated for new parents)

14.1 Google Drive Setup

Google Drive must be configured before teachers can upload photos and videos. This is a one-time setup.

1
Create a Google Cloud Project at console.cloud.google.com.
2
Enable the Google Drive API.
3
Create OAuth 2.0 credentials (Web application type). Set the redirect URI to your school's Oakit URL.
4
Use the OAuth Playground to generate a refresh token with drive.file scope.
5
In Oakit, go to Settings → Google Drive → Configure. Enter Client ID, Client Secret, Refresh Token, and your Drive Folder ID.
6
Click Test Connection. A green tick confirms it's working.
OAuth tokens expire

The Google OAuth refresh token does not expire if used regularly. However, if the Google account changes its password or revokes access, you will need to regenerate the token. Teachers will see upload errors if Drive credentials are invalid.
